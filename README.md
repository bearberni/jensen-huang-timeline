# 黄仁勋事件档案

静态 GitHub Pages 页面。完整档案与 TL;DR 速读版共用同一份内容，区分官方文件、媒体报道、匿名判断及待核数据。

## 页面

- `index.html`：完整时间线、证据分级、市场比较、原始文件与来源索引。
- `tldr.html`：同源生成的速读版。

## 更新内容

`data/content.json` 保存时间线、来源、官方文件和保留的历史回应。`data/summary.json` 保存两版共用的摘要与观察点。`data/visuals.json` 保存三轨事件图，`data/relationships.json` 保存人物、机构、关系端点与证据。`scripts/visuals.py` 生成两版共用的可视化；市场模块为 `templates/market.html` 和 `assets/market.*`。

修改内容后运行（只需 Python 3 标准库）：

```sh
python3 scripts/build.py
```

生成的两个 HTML 与资源一起提交至 `gh-pages`。`.nojekyll` 保持静态发布。

## 编辑规则

- T1–T4 对具体命题分级，不代表媒体排名或概率。
- 访问状态与置信度分开；转载同一原稿不算独立证实。
- 同时写明报道日期、事件日期及后续更新，避免用后来的结果证明先前全部内部过程。
- 股价比较统一字段和交易时段；当前图形仅含所列交易日收盘值，不插值成未核实的分钟走势。
- 支持发言不等于签署；署名以本人原帖核验。
- 历史传播统计没有可复算明细的部分保持待核，不用于推断总体舆论。
